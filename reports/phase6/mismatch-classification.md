## How each category is defined and why it is expected

* `crossing_flip:filter` / `crossing_flip:car`: the below-threshold comparison differs at a crossing; the margin change is `e_filter + e_car − e_baseline + e_offset`, and the label names the largest term. The filter term is truncation toward zero (below).
* `crossing_flip:sigma_offset`: calibration offset error dominates (float-only is more frequent because truncation noise and the +0.12 % gain raise the integer σ slightly, lowering the integer threshold).
* `peak_near_tie`: crossings agree but the minimum is a different sample; the float values at the two positions differ by less than the error at those samples.
* `refractory_cascade`: crossing flags agree, but an earlier mismatch on the same channel changed `last_peak`.
* `candidate_cascade` (events): candidates inside the merge neighbourhood differ, so the group differs.
* `merge_amplitude_error_flip` (events): candidates and merge group are identical; the winner differs because the measured amplitude deviation of the members (bounded by baseline error, filter error, CAR error, σ error, Q8.8 resolution) reverses a near-tie.

## Implementation defects found (all in the `fixed-v1` specification/model; fixed in `fixed-v1.1`)

1. `MAD→σ` Q16 constant was 97157; `round(65536/0.6744897502)` is **97164**. Clip constant was 582 964; correct **582 983**. Found by re-deriving the constants for the independent-oracle tests (relative errors 7e-5 and 3e-5; event effect < 0.02 %).
2. The ADC code shifted by 10 guard bits was not saturated to s24 (codes beyond ±8191 entered the filter as >24-bit words). Native 10-bit data never reach this; fixed with a saturating input stage, tested with the s16 container extremes.
3. Mean-CAR reciprocal used a floating-point `round`; replaced by an integer expression with identical values.
No defect was found in the filter, median, calibration, detector, veto or merge logic: every disagreement is attributed to the quantisation effects above, and the independent oracle agrees with the model bit for bit.
