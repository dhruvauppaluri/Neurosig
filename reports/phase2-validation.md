## Measured results

- NSG1 EVENT/SNIPPET assembly is order independent and emits one logical event per ID at session end. Tests cover missing partners, duplicates, sequence gaps, CRC corruption, capacity, FIFO drop, and backpressure. Packet bytes are generated by Python; RTL provides event triples only.
- Synthetic localization median/p90 errors (µm): amplitude 41.3/97.6, template 24.2/45.8, spatial scan 43.2/69.1, weighted scan 35.0/58.3. The fixed template grid matches the test forward model. MEArec has one source and nine spikes; template median error was 32.7 µm there.
- Raw IBL insertion `4836a465-c691-4852-a0b1-dcd2b1ce38a1`, session `caa5dddc-9290-4e27-9f5e-575ba3598614`, probe00, t=100–101 s, 32 VISp channels. Sorting revision 2024-05-06; trial revision 2025-03-03. Median axial disagreement to sorter peak-channel depth: amplitude 30.9 µm, template 40.0 µm, spatial scan 35.0 µm. The sorter channel is a position proxy, not ground truth.
- The unchanged six-sigma floating detector on native 30 kHz voltage found one event and matched none of 294 sorter spikes assigned to selected contacts within 1 ms. Raw detection transfer therefore failed this pilot. Sorter-triggered waveforms were used for localization; IBL trial decoding used processed sorting and mean waveforms, not the raw detected event.
- Synthetic no-leakage A/B/C mean accuracy across seeds 20261103–05: 81.38% / 81.38% / 82.03%. IBL sorted visual-trial A/B/C: 70.37% / 70.99% / 70.99% versus 57.41% majority baseline. Detailed confusion matrices, class metrics, latency, model size, and estimated-location perturbation sensitivity are in the JSON reports.
- The dashboard was manually opened in a browser; the brain mesh, localization selector, same-event method comparisons, provenance, and offline report panel rendered. API and bridge tests passed. The offline panel is not live ASIC telemetry.

Reports: `edge-integration.json`, `localization-benchmark-v2.json`, `edge-decode-v2.json`, `ibl-pilot.json`, `ibl-decode.json`, and `rtl-pipeline-validation.json` in this directory.

## Limits

The raw IBL detector has not been recalibrated for this session or validated in RTL at 30 kHz. IBL location reference and waveform-derived location features are imperfect; the latter are transductive across the recording without using labels. The IBL trial decoder is not an end-to-end raw AP decoder. Synthetic and MEArec sample sizes are small. No synthesis, timing, area, or power claim is made here.
